# Responsible disclosure

Please report suspected vulnerabilities privately before publishing details.

If GitHub offers a **Report a vulnerability** button on this repository's Security tab, use it. Otherwise, contact a repository maintainer through their GitHub profile and request a private reporting channel. Do not put vulnerability details, credentials, private records or real database files in a public issue.

Include the affected release or commit, the commands needed to reproduce the problem using invented records, the expected and observed results, and the potential impact. A minimal reproduction is more useful than a copy of a real organization's data.

Maintainers will assess the report, discuss remediation with the reporter and coordinate disclosure when a fix is available. This document does not promise a response time or support period. Ordinary defects without a security impact can use the bug report issue template.
